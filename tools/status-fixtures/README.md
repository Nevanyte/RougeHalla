# Status source oracle, revision 1

This is source capture and admission evidence, not a Rust status implementation. `parity/legacy-capture/status-probes.ts` calls unchanged source exports inside genuine `createGameWorld` assembly. Private lifecycle routines run through their actual exported callers and installed hooks; no source body is exported, rewritten or replaced.

Run `tools/status-fixtures/capture.sh` to capture and recapture, or `tools/status-fixtures/capture.sh --check` for nonwriting fixture bytechecks. `RH_STATUS_PREFIX` locates the completed pinned tool environment; `RH_STATUS_OUTPUT` chooses a writable output directory (default `<prefix>/status-source-work/output`). The wrapper uses cached Docker `c86ecead9e55 --pull=never --platform linux/amd64`, read-only `/repo` and Node binary, executable dependency tmpfs, and `npm ci --ignore-scripts` against the unchanged lockfile. Only Linux amd64 Node22.23.4 is canonical. No host Node result is claimed. The image's default Node is not used.

The two fixed inventories contain 42 helper cases and 32 field/ledger/lifecycle cases. Every kind covers duration refusal, max/live extension, equality expiry, stale find/reuse and stable removal. Other cases cover cross tag/ability string identity, retained source metadata, zero/negative values, all cleanse classes, next-tick half-open reveal, complete cast facts, Bow Draw cancellation, source attack reveal, optional-data assignment and shared immunity clocks. Runtime cases cover actual collection/FIFO payouts and explicit next-tick `deferHit`, death-floor accounting after barriers, fields/mirrors/cleanup, generic/ability DoT, landed sustain, shared PvP DoT caps, crit accumulator caching, Mark/zone substitution and displacement/history/path/locks.

`case-inventory.json` and `source-inventory.json` are strict ordered/name inventories. `validate.py <helpers.json> <runtime.json>` admits the fixture structure and executes deletion/duplication/reorder/unknown/missing/narrowing/raw-key negatives. It is an admission check, not a mechanics oracle. Source input and actor IDs remain strings, and optional values retain source distinctions. Raw JSON duplicate keys and nonfinite numbers are rejected; existing private runtime nonfinite sentinels are explicitly tagged output data.

Each snapshot includes a bounded `runtime` projection for native comparison plus the full enumerable source World data, modifier rows/sums/mirrors, clock, aliases and RNG evidence. The bounded projection includes ordered fighters, complete status metadata, body/weapon/cast/crit state, ordered fields and schema mirrors, dot buckets, ledger/landed/deferred/events and payout names/cardinality. Function registration chains are excluded from data serialization; exact source hashes and comparison against an untouched run bind actual execution. Queued closures are opaque: their names/order/cardinality are recorded, and typed input recipes plus actual hook/execution effects prove timing. No expected closure payload is invented. `RaidState.tick` is the sole source `noSync` field and is explicitly captured in every clock. Existing mod WeakMap caches stay with their owner; actual rows/sums/mirrors are read through source exports.

The input contract is `setup.input` followed by `operations`. `setup.initial`, every before/after, returns, hooks and RNG continuations are assertions only. Native adapters must never restore them between operations. The setup records actual factory/config/map/players/clock and trusted overrides. Position overrides also reset source rewind history; complete cast overrides refresh source effects. Source-generated field aliases resolve from the actual return of each `addField`, not an expected field ID. Role setup uses the actual source `addMob` constructor for mob/quest helper facts; this is not a native mob-store claim.

All cases except `ordinary-axe-owner-departure` are trusted helper or synthetic boundaries, including nonneutral modifiers, arbitrary/historical string keys, cast facts, fractional clocks, explicit missing-attacker/arena flags and supplied Mark scratch input. They do not claim naturally reachable ability/card/Mark producers. The ordinary axe trace uses actual intake and source weapon production, then genuine owner departure; it proves retained attribution to an allocated departed fighter, not a never-allocated future ID. The trail-departure case uses trusted field input and genuine owner removal. `isEvading` currently always returns false; no invented evasion state is injected.

`{$undefined:true}` distinguishes undefined returns/payload own-properties from null, empty lists and missing keys. In operation inputs it is admitted only as an explicitly present optional StatusApply data value; the recorder itself calls source with actual JS undefined. Omitted data keys retain prior values, explicit undefined clears them, and stale freshness deletes reveal fields only. The source-case recipes are immutable inputs and cloned for each execution. Numeric values retain Node JSON binary64 rendering; native comparisons should use the existing continuous comparison policy, with exact discrete outputs/order.

The recorder injects all three source streams. Continuations are obtained from fresh actual PRNG factories advanced by observed draws, never by consuming the world stream during a snapshot. After each case, the actual world's next four outputs are compared to those cloned continuations. Untapped and observed runs must agree on full scoped/enumerable data and every returned result. Crit DoT uses the actual deterministic `critAccDot`/tick cache, not an invented random roll.

The frozen external manifest binds all owned files, source hashes, exact case inventories and logs. No source packages, live checkout, Cargo lock or Rust core are changed. Remaining ability/card/mob/terrain producers, destination selection, native integration/checkpoint/privacy/allocation gates and full-workspace checks belong to their packet owners.
