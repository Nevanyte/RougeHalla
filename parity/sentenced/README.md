# Bounded base-player Sentenced source evidence

This evidence covers eight current, power-zero players using the exact existing `HOLY_MODULES` installer order with base Sentenced, Holy, Plague, Fire and Frost. It does not install Sentenced hunt, Fire roam, Plague corpses/zombies, cards, mobs or other auxiliary producers. Earlier modes and fixtures remain intact; default mode is Off. Protocol5 still omits the new faction effects.

`source-manifest.json` pins the accepted package source, source capture code, runtime and fixture bytes. The isolated capture image advertises misleading metadata: its default binary is Node24.22.2. These captures explicitly execute the locally downloaded Linux/x64 Node22.23.4 binary. New Sentenced captures and helper scripts reject another runtime. The minimal image has no git executable, so fixture `legacyRevision` is honestly `unknown`; the manifest records the host-verified accepted baseline and exact package source hashes instead.

No Mark progression, target, ledger entry, projectile or damage event is injected in these scenarios.
