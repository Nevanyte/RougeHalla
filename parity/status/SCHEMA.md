# `rh-status-probes/1` source evidence

Top-level `shared` and ordered `rules` are actual source data. `provenance` binds Linux amd64 Node22.23.4, binary SHA, original package/source and recorder SHA values. `slice` selects the exact ordered list in `tools/status-fixtures/case-inventory.json`.

A case has a declared classification/boundary, `setup.input`, immutable `operations`, assertion-only `setup.initial`, and one `steps` row per operation. A step records the same operation, before/after snapshots, immediate return and actual ordered appended hook observations. No expected snapshot is an input. Helpers with source-generated aliases must resolve their own actual return IDs.

`setup.input` declares seed, all stream salts, config/module flags, map rows, actor setup, initial clock and explicit trusted overrides. The factory joins Alice/Bob/Carol, takes one real source step to start the run, places them and resets rewind history, sets the declared clock, constructs optional source mob/quest helper roles, then applies declared overrides. Position overrides reset history; cast facts refresh source effects. Trusted Mark suppression is supplied input to the actual source ledger, not its computed answer.

Every snapshot has `runtime` for the status packet comparison and full source evidence alongside it. `runtime.clock` includes the authoritative noSync tick. Ordered fighters include identity/role/standing/name/vitals/effects/sig, actual modifier mirrors, full ordered status records, full weapon state/ready time, cast facts, body/path/history/slip/displacement sequence, and DoT critical accumulator/tick/result. It also records entityCounter, optional actual Mark scratch, ability runtime/fields/schema mirrors/dot buckets/clocks, events, ledger/landed/deferred/collection/payout sequence, callback outcomes and all stream draw counts/continuations. Native integrations compare only their declared supported projection and fail explicitly for unsupported cases.

Undefined is `{"$undefined":true}`, distinct from null, empty arrays and missing keys. It is an input marker only for explicitly present optional `apply.data` values; capture calls source with actual JS undefined. Optional status payload fields remain sparse. Existing source NaN/Infinity sentinels use `{"$number":"NaN"}` or signed Infinity strings in output only. Payout closures use opaque `{"$function":"name"}` entries; no captured closure payload is invented. Exact FIFO execution is checked through declared operations, immediate returns, complete effects/state and ordered hooks.

All continuous data retain Node JSON Number rendering and use the repository's existing continuous comparison policy; discrete outputs, key presence, enums and ordering are exact. See `tools/status-fixtures/validate.py` for closed operation fields, fixed inventories and checked narrowings. Source-symbol coverage and explicit unported producers are listed in `source-symbols.json`.
