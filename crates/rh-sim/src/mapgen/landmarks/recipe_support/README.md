# Shared read-only landmark support

This leaf contains common planning inputs and helpers only. It does not contain faction recipes, template rows/jobs, callback dispatch, stage-4 integration, finished-map generation, canonical pins, or certification.

`RecipeInputs::new(seed: i64, attempt: u64, fixed, fixed_rules, rules)` borrows immutable inputs and reuses attempt safe-integer admission. Seed and attempt are private after validation. `streams(zone)` returns immutable independent stream metadata; `rng()` returns a fresh Mulberry32 continuation. No API accepts the attempt's main RNG. `camp_nodes(runtime)` reads the current runtime collision each time; the optional-distance standalone helper also supports non-generator direct probes. Territory remains exclusively the runtime transaction's optional immutable grid, exposed by coordinator-owned `runtime.territory()`; this leaf neither copies nor substitutes it.

`RecipeSupportDefinition` is the single live common policy definition. Its six fields drive area/length scaling, common landmark upper limit, independent stream/noise selection, and door distance filtering. `visit_content` emits those six words in declaration order without allocation. It borrows the corresponding existing `FixedDefinition` alongside `FixedLayout` and reads that definition's `ring_road`, including custom definitions; there is no second ring knob. DIR16, binary hash multipliers, 32-bit coercion, noise quantization, graph doubled-midpoint arithmetic, and circular direction modulus are fixed source encodings, not additional policy knobs. `js_round` reexports the established `crate::math` implementation; ToUint32 and seed mixing reuse existing attempt/RNG helpers.

The bounded helper surface comprises hash2/value-noise/noiseQ, JS rounding, area/length scaling, campNodes, Gabriel edges, DIR16/dirSep16, isqrt/dist2, and argmaxIn. It deliberately has no fBm, MST, terrain, route, lake, crater, or visual-style functionality. Integer geometry helpers accept finite source-domain coordinates; isqrt requires a number no greater than the JavaScript safe-integer bound. argmaxIn accepts an integer half-open range and a mask covering its field. Camp coordinates/indices come from the established runtime geometry.
