The caller owns earlier map stages, contract checks, certification, retries, exports, and aggregate content identity. `visit_entries` visits the actual dispatch metadata, and `visit_content` delegates to `ENTRIES`; leaf tuning stays with each existing definition owner.

One mutable State retains durable layers, shared write counts and BFS scratch across zones. Cached component counts follow source sequencing. A route guard is built before writes when the caller supplies centre-walk data and that zone has filtered spawns. Gallows has no surface context or surface stream. Source phase streams are private to callbacks.
