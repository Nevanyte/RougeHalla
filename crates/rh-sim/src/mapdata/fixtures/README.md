# Real legacy full-map exports

Generated by `tools/map-fixtures/full-map.ts` on Linux x64 Node **22.23.4**. `seed1.map.json` and `seed2.map.json`
contain explicit complete `rh-map/2` documents from the actual `certifiedMap(seed, {decor:false})`. The tool also
runs `generateMap(seed, acceptedAttempt, {decor:false})` and requires every exported field to match. It rejects
changes to the runtime GameMap key set instead of accidentally dropping a new field.

`oracle.json` records runtime provenance and direct `regionAt`/`bushAt` results for all 25,600 tile centres per map
plus world-boundary samples. It is a test oracle, not part of the import schema.

- Seed 1: accepted attempt 0, captured legacy map hash 3499839449.
- Seed 2: accepted attempt 0, captured legacy map hash 420271375.

Run the same tool with `--check` for byte-for-byte recapture. Captured hashes remain unverified legacy metadata
until the complete Rust hash/generator work exists. No legacy pins were regenerated.

`domain-maps.json` additionally captures real certified producer calls with seeds **-1** and **4294967297**, plus
`tryAttempt(1, 4294967296, {decor:false})`. Their signed and large seed/attempt metadata is preserved without uint32
coercion. These documents roundtrip every field through Rust; the oracle hash is still not recomputed in Rust.
