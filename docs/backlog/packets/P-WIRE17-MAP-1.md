## 1. ID and outcome
The Unity minimap and Tab map cannot show camps, because the map blob the server sends holds only collision tiles, the
terrain grid and the region grid. Legacy clients generated the whole map themselves, so camp positions, coliseum gates
and concealment bushes were public to every client. When this lands the protocol is version 17 and the map blob has new
optional sections: camp markers (position, radius, zone; index-aligned with the `WireCamp` rows already in state),
coliseum rectangle and gate tiles, and a bush plane (0 none, else bush id) so real concealment can be drawn. Two more
optional sections are reserved and decoded but left empty by the server until the dressing packets: cosmetic props and a
ground-variant plane.
