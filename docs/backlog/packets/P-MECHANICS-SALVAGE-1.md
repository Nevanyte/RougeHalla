## 1. ID and outcome
`fix/mechanics-sim` (gated on 2026-11-10 with `integration/launch-fixes`, never merged) ports legacy combat rules
that the integration branch does not have: bruiser camp clears, `armWishes`, Best Offense block hits, returned
on-hit effects, axe shred, riposte, and backlash. Their absence is a real difference from the legacy game's balance:
the owner's first complaint about the beta was that classes did not feel like the old version. The branch cannot be
merged as it is: it also ports Holy camp lifesteal a second way (the integration branch has it from
P-HOLY-DEMON-BLOOD-1), and it moves the content hash. When this lands each of those mechanics, except the Holy
duplicate, is on the integration branch, taken from `fix/mechanics-sim` where its code still fits and re-ported
where it does not, with the content hash, fixtures and the Unity baked hash moved in the same branch.

none. Strictly serial with any other packet that edits `crates/rh-sim/src/systems/` combat files or moves the content
hash (P-CAMP-BUFF-THEMES-1, P-FROST-WALL-1).

## 11. Known traps
