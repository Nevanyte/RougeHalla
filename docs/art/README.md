# Roguehalla visual art board

Open [index.html](index.html) in a browser for the curated preview board and visual direction.

The selected primary family is Flare game art: credited fantasy characters with animation frame/anchor metadata and a matching isometric dungeon tile atlas. Original source assets, exact upstream definitions, pinned commit, checksums and license records are kept under `client-unity/UnityProject/Assets/Art/ThirdParty/Flare/`. The Unity-facing frame inventory is `sprite-frame-metadata.json`.

The source images are unchanged. No Asset Store package, audio asset, 3D asset, paid asset or generated art was acquired in this pass. See [client-unity/THIRD_PARTY_ASSETS.md](../../client-unity/THIRD_PARTY_ASSETS.md) for redistribution and attribution rules.
