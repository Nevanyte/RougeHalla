# Original interface, cosmetics and audio inventory

Source snapshot: `70579162ce41a1325aaed1a65a34b65b779ad1e7`. This includes the full original client, including screens outside the one-match showcase milestone.

The original has **no checked-in image/audio/font media files** in `packages/client` (excluding generated outputs/dependencies). World art uses procedural Phaser graphics/baked textures; UI uses DOM/CSS and generated SVG. No original audio playback path was found. Unity audio is new presentation work.

`available` in the older transport inventory means facts can be consumed. It does **not** mean Unity has that screen or finished artwork. The table below reports actual art/runtime gaps separately. Protocol13 Wish/barrier paths are corrected here; accepted five-faction/Trophy browser proof remains accepted.

## Exhaustive source index
