# Portable evidence

`summary.json` contains the exact runtime identity, all 19 required browser outcomes, test counts and nine profile windows. `build-manifest.json` pins the distributable files. Full raw browser reports and action logs remain in the local evidence directory documented in [VERIFICATION.md](../VERIFICATION.md).

The screenshots include Flare artwork and derived composite atlases. Preserve [the asset credits and licenses](../../../client-unity/THIRD_PARTY_ASSETS.md), including Flare CC BY-SA 3.0 and its original contributor notices. UI, effects and floor/wall texture code are original project work.

The staged `art-study.png` is an art review, not a live match or gameplay/performance proof. `live-combat.png` is captured from the native eight-seat run. The native 144 Hz acceptance condition is explicitly incomplete; uncapped callback rates do not prove displayed FPS.
