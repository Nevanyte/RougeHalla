# Full-pixel Flare base catalog import

`Roguehalla.Editor.FlareFullBaseImporter.Import()` reads the original retained Flare Raw definitions and PNG bytes, then writes a new isolated `ShowcaseCatalog` to `Assets/Art/Derived/FlareFullBase/Catalog.asset`. It does not overwrite `Assets/Art/Derived/Flare/`, mutate `Assets/Resources/Showcase/Catalog.asset`, edit the preserved `OriginalSourceCatalog.asset`, or alter any source `.meta` or texture importer.

## Inputs and actor composition

The five keys are `knight`, `goblin`, `skeleton`, `hero`, and `hero-female`. The knight is stance-only; its other seven catalog clips are empty arrays. Goblin and skeleton use their original single layers. Hero and hero-female compose six original plate layers, in this order: `plate_boots`, `plate_greaves`, `plate_cuirass`, `plate_gauntlets`, gender-specific `head_short`/`head_long`, and `plate_helm`. Every non-knight source must have all eight catalog clips (`stance`, `run`, `swing`, `block`, `hit`, `die`, `cast`, `shoot`) with contiguous frame indices and all eight direction records. Layered appearances must have matching direction/index coverage and matching authored FPS for each clip. Original extra sections such as `run_alt`, `critdie`, and `shield_bash` are outside the existing catalog contract and are not imported.

The compositor preserves the old straight-alpha source-over order. It decodes each raw PNG sequentially with a temporary `Texture2D.LoadImage`, copies only source pixels with nonzero alpha, and releases the temporary texture before opening the next layer. It does not resample or transform source pixels. For each opaque source pixel, it applies `localX = 194 + x - PivotX` and `localY = 79 + sourceRowFromBottom - frameHeight + PivotY`. An opaque pixel outside the 388px cell or inside the two-pixel border is a hard error. Transparent metadata padding at or beyond the border is allowed.

All frames use 388×388 cells, 16 columns, anchor (194,79), and 128 pixels per unit. The source art's pivot-relative visible pixels therefore keep their original world position and physical pixel scale at the existing `WorldHeight = 1.15`. The normalized Sprite and `GroundPivot` anchor is (194/388,79/388). Source-authored clip rates are preserved; missing rates retain the legacy 10 FPS default.

## Output and audit receipt

Each import writes PNG atlases into a content-addressed directory under `Assets/Art/Derived/FlareFullBase/Versions/<run-id>/Actors/`. The run ID comes from SHA-256 hashes of every participating definition and source PNG. Atlases are imported as non-sprite Default RGBA textures with alpha, no mipmaps, NPOT None, clamp, CompressedHQ, and max size 8192. New `Sprite.Create(..., SpriteMeshType.FullRect, ..., generateFallbackPhysicsShape:false)` objects reference those persistent atlas textures and are added as subassets of the separate catalog; the importer does not author sliced importer metadata.

The catalog copies props, audio clips, the optional `ShowcaseAudioLibrary`, and mixer-group references from the preserved `Assets/Art/Derived/ShowcaseLive/OriginalSourceCatalog.asset` template. Only the five actor appearances are regenerated. The generated `receipt.json` records SHA-256 hashes for every participating Raw definition and PNG, atlas hashes/dimensions, clip frame counts and slot totals, pivot-relative opaque bounds, and per-clip counts of opaque samples that the old 224px cell compositor discarded. For layered heroes it also records unique absent pixel sites after unioning overlapping source-layer locations.

Rebakes keep the stable `Catalog.asset` path and place atlas versions under separate content-addressed folders. New sprites are attached before catalog fields change; old generated Sprite subassets are removed only after the new catalog and receipt save. On errors, the importer attempts to restore the prior catalog and receipt and removes only generated assets created by that invocation. The Raw source files and old import outputs remain untouched. Unity Editor compilation and save/domain-reload checks remain required before adopting this catalog as the compact baker's source.
