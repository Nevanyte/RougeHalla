# Terrain vignette preview component

`ShowcaseTerrainVignette` is a presentation-only study patch for a newly created Unity root. Call `Configure(ShowcaseTerrainArt terrain, Vector2 worldSize, bool optionalLight = false)` once for each authored preview patch. It accepts only the four explicit art enum members (`Lava`, `HealingLight`, `Ice`, `Bog`); invalid enum values leave the root unconfigured. Dimensions are checked for non-finite or non-positive values and clamped to a bounded preview range.

The component reads the procedural surface and alpha mask from `ShowcaseBiomeArt.Terrain`, uses `ShowcaseSprites.Lit` for the normal-lit surface and `ShowcaseSprites.Unlit` for the always-readable silhouette marks and bars. A private unlit material carries the mask's HDR tint. The project Bloom volume can pick up that color; the ordinary surface, distinct central glyph, dark backing, and four pale edge bars remain visible without Bloom or point lights. The surface glyph geometry differs by terrain so identification does not depend on hue. High quality may enable one optional `ShowcasePointLight` using the existing Torch/TorchAccurate presets. Medium and Low use the static mask only. Missing light presets leave the static art unaffected.

Each patch owns one looping decorative ParticleSystem with `maxParticles = 16`. Quality changes set its bounded rate to 3/s (High), 1/s (Medium), or 0 (Low); reduced motion stops and clears it. Reduced motion and quality changes never hide the surface, glyph, glow mask, backing, or boundary. `OnDisable` unsubscribes safely, stops and clears particles, and hides the light. `OnDestroy` destroys the two private materials and its child objects. Cached sprites/textures are shared through the existing `ShowcaseBiomeArt` and `ShowcaseSprites` providers; their application-level cache teardown must happen only after all vignette roots are destroyed.

This component has no collider, damage, healing, status, terrain-selection, map-placement, or network behavior. The preview owner should instantiate only a small study set (for example, five patches) and keep optional point lights to at most four in the scene. Do not connect a terrain enum to a live map until public map facts identify that terrain. The glow layer is an HDR-tinted colored alpha mask; it relies on the project's Bloom configuration and does not implement gameplay effects.
