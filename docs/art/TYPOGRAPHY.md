# UI typography

The match HUD uses **Cinzel Decorative Regular** for the four display headings (`Title`, `RewardTitle`, `ResultsTitle`, and `SettingsTitle`). The runtime helper loads its generated TextMeshPro asset from `Resources/Showcase/CinzelDecorative`; body copy, controls, and numeric HUD values remain on the readable Liberation Sans SDF.
