## Explicit remaining coverage limits

- This is a finite private method suite. It does not certify every combination, every comparison boundary or every V8
  branch. Complete native class implementations remain required; an unwitnessed source branch cannot become a stub.
- StrategyOptions.attacking's explicit getter is exercised by real HuntAdapter option histories. The private Strategy
  attacking getter's separate positive branch is not isolated by a dedicated sequence; its fallback is exercised in
  fight/pursuit histories. Preserve both source paths; do not claim exhaustive caller-option coverage.
- `mobLikeOf` receives only real Memory mobs in the coupled cases; createMemory itself excludes nonregional kinds.
  Its separately exported nonregional early-return and every unknown-name/null-zone fallback are not independently
  enumerated. Source class behavior must remain complete even when the real-Memory seam cannot produce a row.
- Module callbacks are finite declared services, including one context-dependent descriptor; production module logic,
  learned persistence and createBrain orchestration are not captured. Exotic module.data JSON.stringify cases beyond
  the recorded ordered `{n:...}` keys are not enumerated. Preserve source generic key semantics rather than specializing
  the implementation to these data examples.
- NullPercept is a caller skip, not FrameRing startup. The Memory HP-credit/lock/event cases are declared method data,
  not proof that all those events were earned from a World/perception chain.
- HuntAdapter homed/lastAt are inaccessible closure storage; effects are bound by continuation/control cases, not by
  direct reflection. The source maxHps global cache is catalog-derived; occupancy is not part of comparison.
- Initial static/module initializer blocks precede V8 profiling; the source's unreachable post-fallback empty-live Idle
  return is not manufactured. Overlapping V8 range counts must be interpreted with their enclosing block ranges;
  simply counting every explicit zero range as an unexecuted source line is incorrect.
- Independent fresh-checkout/runtime reproduction is Root's next source admission gate. The sealed local bytecheck,
  successful controls and recreated instances do not relabel that independent gate as passed.
