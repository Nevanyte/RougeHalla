# Approved source numeric boundary

Root approved this field-scoped inheritance before freeze. All source values are retained unrounded. The native path
whitelist still requires independent review; this document does not approve blanket approximate comparison.

Exact: raw declared inputs/config/map records, all eight Memory surfaces/whereabouts and stimuli, all tags/nonfinite
classification/signed zero, Map/object/array ordering, source RNG outputs/count/order, strings/why/choice, goal kind and
identity/current reuse, callback identity/order and declared/discrete arguments. Exact binary64/source evaluation order
also applies to pure arithmetic state: goalSince, chase since/limit, avoidUntil, excluded/lootSkip, judged.until,
flee/retreat/ban/pick/expiry clocks, catch-up times/focus counters, module utilities, flee depth/utility/until and source
comparisons. No FMA, rounded input shortcut or f32 conversion.

Permitted inherited bounds are only:

1. Existing bot-core `1e-9*max(1,abs(source))`: Strategy own judged Map values' z from source Gaussian log/sqrt/cos;
   normal-hunt appraisal/gate-derived candidate/result utility; Farm rewardCurve/exp-derived utility; coliseum Hunt
   sigmoid-derived utility. Projected duplicate leaves may use the same classification. Cached until remains exact.
   Softmax intermediate math is not directly exposed in this fixture: its chosen index/outcome and RNG use are exact.
2. Existing geometry `2e-6` absolute: actual source-created hypot/path distances, source BuildRoute route arrival/start
   estimates when derived from those distances, distance-weighted camp/loot/patrol utility components and their
   projected duplicates. A startAt selected from the raw respawn deadline is exact; it is not a geometry estimate merely
   because another branch of that field can be. Callback `paths.walk` return.dist and `hunter.walk` return, and remembered
   enemy `knowledge.odds` argument dist computed by source hypot, can share this whitelist.

Copied coordinates in current source goals/from/positions are raw self/percept/map/Memory points and remain exact.
An on-screen fighter's dist is a declared raw input and remains exact even though a harness builder originally computed
it with hypot. A remembered enemy's strategy dist is recomputed inside source and is the geometry case. Geometry never
licenses approximate IDs, picks, near-range predicates, returned waypoint topology or rounded why/log strings.

Knowledge odds' wheels/tint/HP lead and mob-share linear/error leaves stay exact. MatchupShare uses the existing source
cached deterministic duel; no new tolerance for that code is introduced here. If another formula/leaf does not fit,
retain its exact source value and report the need before broadening the comparator.

References: CONTRACTS C-NUM/ADR0007; parity/README113–119 (`2e-6` continuous libm/V8 allowance, exact discrete results);
existing bots/parity_tests.rs8/55 (Gaussian/humanizer bound because Math.log differs from policy Newton ln); admitted
Memory/source_tests.rs380 compares to_bits. The old geometry corpus rounds1e-6; this source corpus does not. No numeric
allowance may hide a changed branch, winner, candidate order, callback/alias, expiry boundary or random consumption.
