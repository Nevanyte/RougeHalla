counts and lossless full callbacks. V8 block ranges/transformed text are retained without claiming that a zero outer range
means nested branches were unexecuted in every other case.

Explicit unisolated or excluded domains: arbitrary custom future ability tags/dir/point-without-blink/nonunit-id policy
combinations are not the current five built-ins; malformed but guard-passing AbilityDefs may still throw in legacy and are
not universally modeled. No iterator side effects, arbitrary prototype graph or nonfinite Plan input is claimed. Hazard
search's pathological no-body-fit/fallback-only redirection geometry, every terrain patch topology, every Plan map/learned
key and every equality across all personas are not independently isolated. Some safe source fallback/guard edges are
captured only through full histories/V8 ranges, not each given a dedicated mutation. Function import/top-level transpiler
setup coverage is not semantic gameplay coverage. No new learned store, skills/relic module or future ML service exists.
Full Brain guards/order/cadence/derived RNG/hand/features/seq1..255/stats/end, fair publication and validated live/headless
execution remain later packets. These are scope boundaries, not silent omissions from the complete bot objective.

Source-only finite adequacy is an author's assessment until independent review. A concrete required gap found in review is
fixed with real source input/continuation evidence; optional cross-product expansion is separate work. Controls compare
derived results/callback schedule/counts/Hunter counters and list identity, never input manifests/config pins as a false kill.
