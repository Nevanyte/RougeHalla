# Numeric and input limits

Start every field exact. Inputs and outputs retain source binary64 without decimal rounding, including all method clocks,
read/settle boundaries, source accepted fractional/large Plan indices and picks, callback values and declared path facts.
Undefined, Null, absent keys, -0 and infinities are distinct. -Infinity card rejection is an actual source sentinel. Ordinary
nonfinite declared clocks/geometry/config numerics are rejected before a consumer receives cases. Only explicitly declared
learned-bias callback returns may be nonfinite because real source Number.isFinite sanitizes that exact field; never coerce
arbitrary nonfinite data to zero. A source accepted malformed Plan payload remains raw private-event data and source readDeal
owns the conversion. The fixture reader does not impose native old i8/i32 PlanDeal restrictions on binary64 source values.

No comparison tolerance is authorized by this source author candidate. A future reviewer may propose a narrowly enumerated
continuous geometry/transcendental whitelist after source review (Math.hypot / trigonometric awayPoint or blink/softmax-derived
continuous outputs). Such a proposal cannot tolerate timer branches, identities, order, chosen option/target, status, reasons,
utility, RNG values/counts or whole input/callback records. A permitted floating difference must not excuse discrete divergence.
The existing strategy/tactics whitelist is not automatically imported. No values were fitted to native results.

Finite scope is the exact enumerated case/operation arrays, embedded8 maps, fixed seeds/configs and callbacks. Config seeds,
path allowance, map dimensions and arrays are deliberately bounded in this corpus; this is not a general hostile live intake,
resource-limit guarantee, whole Brain proof or universal JS semantics implementation. Native atomic reader must validate the
complete supported descriptor before any Memory/RNG/module/service mutation, and report unsupported domains explicitly.

This is an explicit finite **method profile**, not an assertion about every value accepted by JavaScript or an unverified
server-producer guarantee. In particular source readDeal accepts `typeof number` for endsAt/spawns/pick/boon, which includes
NaN/±Infinity in JS. Such nonfinite Plan declarations are intentionally excluded here (endsAt is a clock); the source does
not reject them on this reader's behalf. Fractional/large finite values and raw malformed-but-finite payloads remain covered.
Likewise the profile enumerates current known phase/status/message strings and array-backed Iterable inputs; it does not
claim every arbitrary direct-call string, iterator side effect or malformed opaque AbilityDef can be replayed.

The enumerated final histories require nondecreasing observed Memory time per cfg, plus independently nondecreasing Hunter now and serverTime. This is a declared trace-profile constraint, not a claim that every backward direct JS call throws. The strict reader rejects a finite backward observation clock before returning any converted case.
