## How to run

```
# a diagnostic tournament with a patch (legacy tune.ts shapes)
cargo run --release -p rh-headless --bin tournament -- --games 40 --tune '{"personas":{"hunter":{"engageEdge":0}}}'
cargo run --release -p rh-headless --bin tournament -- --games 40 --tune '{"ablation":true,"tiers":{"easy":{"knowledge":0.95}}}'
# the search (meaningful only after P-BOT-BRAIN-CONTINUITY-1)
cargo run --release -p rh-headless --bin tune -- --seed 1 --generations 10 --population 4 --games 24 --out brain-search.json
# regenerate the checked-in table (must stay equal to the compiled tables; a test checks it)
cargo run -p rh-headless --bin tune -- --write-compiled crates/rh-policy/data/brain_tuning.json
```

The search file records format, seed, commit, plan, objective (text, win bands, spread weight and floor), search
settings, every leaf's bounds, every scored proposal (generation, changed leaves, score, spread, accepted), and the
best table in the checked-in table format. Adopting it is a separate reviewed change with a DEVIATIONS row.
