# Owner decisions: an index

This file is an **index, not the record**. The record is where each row points; when a row and its record disagree, the record wins. The coordinator adds a row in the same commit that records a decision in `docs/MIGRATION.md` (and a row for any DEVIATIONS signature or ORDER_OF_OPERATIONS decision).
**Use:** search this file for the subject before writing a brief or an oracle; a brief that touches a decided subject cites the row (date and subject). A row marked "brief only" is recorded nowhere else: the coordinator should add it to MIGRATION.
**Keys:** MIGRATION = `docs/MIGRATION.md`, DEVIATIONS = `docs/DEVIATIONS.md`, OOO = `docs/ORDER_OF_OPERATIONS.md`; a bare `P-*.md` is under `docs/backlog/packets/`. `L123 "text"` is a line number and a quote found on that line (as of the commit this index was built on); the quoted heading or phrase is the durable key if lines move. Quoted words are the record's own. Rows marked "proposed" or "unsigned" are NOT decisions.
